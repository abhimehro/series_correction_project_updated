## 2024-05-24 - NumPy Native NaN Handling
**Learning:** In NumPy, array operations like `np.median` natively propagate `NaN` values, meaning any slice containing a `NaN` inherently evaluates to `NaN`. Manually calculating boolean masks (e.g., `np.isnan(chunk_windows).sum(axis=1) > 0`) to re-assign `np.nan` to the result array is mathematically redundant, incurs an O(N) performance overhead, and pollutes code readability.
**Action:** When computing aggregations over sliding windows or arrays with potential NaNs in NumPy, rely on the native NaN propagation behavior of standard functions (or explicitly use their nan-ignoring variants like `np.nanmedian` if propagation is *not* desired) rather than writing custom masking logic.
